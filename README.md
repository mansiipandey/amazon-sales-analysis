# Amazon Sales Analysis
Amazon Sales Analysis project — a comprehensive data analytics project focused on exploring and understanding sales trends, customer behavior, and business performance using Amazon sales data.

This project leverages Python, Data Analytics, and Visualization techniques to analyze sales patterns, product performance, revenue generation, and customer insights. The goal is to transform raw sales data into meaningful business intelligence that can support better decision-making and strategic planning.

## Getting Started
To get a local copy of this notebook up and running on your machine, follow these steps:

1. Prerequisites
   
🔹Google Colab account (if you want to run the notebook in the cloud).
🔹Jupyter Notebook (if you want to run the notebook locally).

2. Installation
   
🔹Clone the repository:
git clone https://github.com/mansiipandey/amazon-sales-analysis.git

3. Navigate to the project directory:
   
🔹cd amazon-sales-analysis

4. Open the notebook:
   
🔹If using Jupyter Notebook, run:
jupyter notebook Amazon_Sales_Data.ipynb

## Dataset Information 

The dataset contains important sales-related information such as:

🔹 Product Categories
🔹 Sales & Revenue Data
🔹 Order Details
🔹 Customer Information
